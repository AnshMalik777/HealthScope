About the project

Understanding healthcare
through data.

HealthScope presents a structured analysis of healthcare records. The project uses data preparation, exploration and visualisation to make complex information easier to review.

Project Overview

The Big Data Healthcare Analysis project explores a healthcare dataset containing patient records and disease-related information. It uses Excel for data preparation and initial exploration, followed by Power BI for interactive reporting and visual analysis.

Healthcare Data Data Analytics Interactive Reports

Project Objectives

The objective is to organise healthcare information, examine patterns across available patient and disease categories, compare recorded measures, and communicate findings through accessible dashboards.

Pattern Analysis Data Visualisation Decision Support

Tools & Technologies

Excel supports data cleaning, organisation, summaries and pivot tables. Power BI is used to create interactive dashboards. HTML and CSS provide the website structure and visual presentation.

Microsoft Excel Power BI HTML CSS

Scope of Analysis

The reports cover demographic distribution, time trends, regional comparisons, risk indicators, hospital insights, social factors, recovery outcomes and healthcare costs, subject to the fields available in the dataset.

Methodology

From raw records
to readable insights.

A structured workflow helps organise the healthcare data, identify patterns and present the analysis through interactive dashboards.

STEP 01

Data Preparation

Inspect the source data, review column formats, identify duplicates and missing values, and prepare consistent records for analysis.

STEP 02

Data Exploration

Use summaries, pivot tables and comparisons to understand the dataset and investigate its main characteristics.

STEP 03

Visualisation

Develop interactive Power BI reports using appropriate charts, filters, KPI cards and other visuals.

STEP 04

Interpretation

Review the visual results, explain the observed patterns and acknowledge limitations in the underlying data.
